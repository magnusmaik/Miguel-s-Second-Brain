## [Framework] Concepto de set como viaje sonoro

*Propuesta derivada de la exploración actual (14 ago 2026) — no es la estructura histórica confirmada de ningún set ya publicado.*

Los sets se piensan como viajes, no como colecciones de tracks:

1. **Inicio** — espacio + profundidad + groove contenido
2. **Desarrollo** — mayor densidad percusiva y microvariaciones
3. **Profundización** — groove más hipnótico y físico
4. **Expansión** — elementos atmosféricos / progresivos
5. **Clímax** — mayor densidad y energía, sin recurrir necesariamente a un drop convencional
6. **Resolución** — vuelta a espacio, profundidad y groove
