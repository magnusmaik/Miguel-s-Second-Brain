## Vender el sistema de adquisición de clientes, no marketing

La oferta no se presenta como "hacemos tu marketing" — se presenta como implementar un sistema completo (tráfico + oferta + funnel + CRM + automatización + seguimiento + ventas). Esa diferencia cambia cómo se percibe el precio, el compromiso esperado del cliente, y qué tan fácil es compararte con la competencia.
