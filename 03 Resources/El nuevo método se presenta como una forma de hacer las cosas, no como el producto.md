## El nuevo método se presenta como una forma de hacer las cosas, no como el producto

Al comunicar una oferta, el "nuevo método" no es el producto o servicio en sí — es la técnica, el recurso o la forma de hacer las cosas que hace posible el resultado. Se sintetiza en 2-3 palabras para que se entienda de inmediato. Nombrar el método le da un marco distinto al cliente frente a lo que ya intentó sin éxito.
